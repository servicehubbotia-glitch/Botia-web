The Code System

A code on the label. A story behind it.

E-numbers are the EU system for identifying authorised food additives. Authorised means they passed a safety threshold — it does not mean they are without debate.

Why this matters

E-numbers are often misunderstood — some are harmless, some are under active review, some have implications for specific groups. What they share is that they are ingredients beyond the basic food components. According to NOVA (FAO, 2019), their presence is a marker of ultra-processed food.

A code only manufacturers fully understand

E-numbers exist only in Europe. In the United States, the same additives appear under the FDA GRAS system with different names. Globally, the Codex Alimentarius uses INS numbers. China has its own GB standards. Australia uses the same numbers but without the 'E'. The result: the same substance can be E471 in Europe, INS 471 internationally, and something else entirely on a US label. Manufacturers know exactly what each code means and where it comes from. Most consumers do not. BOTIA exists to close that gap.

The same additive can be banned in Europe and authorised in the United States — or the reverse. E171 (titanium dioxide) was prohibited in the EU in 2022 after EFSA concluded it could no longer be considered safe. It remains authorised in the US. The code changes. The substance does not. BOTIA flags what the label declares and connects it to what the science says — regardless of which system named it.

What BOTIA looks for

BOTIA detects E-numbers flagged for one or more of the following reasons: potential hormonal activity (E171, E320, E321), insect origin (E120), animal origin uncertainty (E471, E472, E322), sweetener effects (E950-E968), or general ultra-processing markers. Not every E-number is flagged — only those with documented relevance.

The code is not the only name

Not every label uses the code. The same additive can appear as E471 or as 'mono- and diglycerides of fatty acids'. Some manufacturers use the number, others use the chemical name, and some use neither on the front of the pack. BOTIA reads both. The code changes, the name changes, the wording changes — the substance does not.

BOTIA CAN

  • Detect E-numbers with documented scientific or regulatory relevance.
  • Link E-numbers to their specific BOTIA layer — animal, muslim, woman, or evidence.
  • Signal when an E-number is under active re-evaluation by EFSA.

BOTIA CANNOT

  • Tell you every E-number is harmful — most are not.
  • Assess your cumulative exposure to multiple E-numbers.
  • Replace medical or nutritional advice.

Not all E-numbers are equal. The same code can mean different things in different countries. Explore the ingredient pages to understand what each one means for you.
